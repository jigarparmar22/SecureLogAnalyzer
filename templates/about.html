About SecureLogAnalyzer

A Windows security log analysis and threat-detection platform.

SecureLogAnalyzer is a web-based security log analysis and monitoring system that helps security analysts and system administrators detect suspicious activity from Windows security event logs. Upload a Windows Event Log XML export, and the platform parses each event, applies rule-based threat detection, and presents the findings through a centralized security dashboard.

Threat Detection Capabilities

{{ icon("alert", 22) }}

Event-ID Rule Engine

Flags known security-relevant Windows event IDs including failed logins, privilege assignments, and account modifications.

{{ icon("activity", 22) }}

Brute-Force Detection

Identifies possible brute-force attacks by detecting repeated failed login attempts within a configurable time window.

{{ icon("key", 22) }}

Compromise Detection

Detects successful logins shortly after a burst of failed attempts — a strong indicator of account compromise.

{{ icon("shield", 22) }}

Privilege Escalation

Correlates new account creation with subsequent privilege or group-membership changes.

{{ icon("server", 22) }}

Log Tampering

Flags security log clearing that follows suspicious activity — a potential anti-forensics technique.

{{ icon("database", 20) }}

Supported Log Format

The platform currently accepts Windows Event Log XML exports (.xml). The parser handles the standard Microsoft Windows Eventing namespace, including events with RenderingInfo rendering data containing human-readable level and message fields.

Maximum upload size: 100 MB.

Technology Stack

  • Backend: Python / Flask
  • Database: SQLite
  • Reporting: ReportLab (PDF generation)

  • Charts: Chart.js
  • Security: Werkzeug password hashing, account lockout, CSRF protection, hardened XML parsing
